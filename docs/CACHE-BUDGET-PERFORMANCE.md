# 缓存预算与现行测量方法

原有阈值实验的公开样本已由本轮 preview.3 的配对测试替换，旧数据保存在本地存档。现行结果见 [优化前后对照](OPTIMIZATION.md)、[CPU 与 RSS](RESOURCES.md) 和 [Native AOT](AOT-PERFORMANCE.md)。

SQL 行缓存按数组、装箱值、UTF-16 文本、BLOB 视图及源后备数据估算预算；它不是整个进程 RSS 的硬上限，辅助索引、运行时、页缓存和结果数组另有开销。预算为零、可容纳表复用、写后失效和 BLOB 所有权均在回归中检查。

当前完整对比以相同测试宿主只替换前后内核，三轮串行轮换旧版、新版和 SQLite；AOT 与自包含 JIT 则重新发布并使用同一运行时。不能把旧宿主或旧内核样本标成新版成绩。
