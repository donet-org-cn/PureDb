## 注释、格式、AOT 与包

主库及兼容库 980 个类型和成员声明通过中文 XML 检查，包含参数、类型参数、非 void 返回值及重要边界。源码严格 UTF-8；两个项目运行 dotnet format whitespace 校验。新增类型和协议方法均配中文注释。

两个平台实际发布并运行 Native AOT，DynamicCodeSupported=false，每平台 7 组功能和 230 条扩展差分、IL 编译/裁剪警告为 0。这些差分是既有语料的重复执行，不重复累计覆盖率。AOT 发布体积、启动、CPU、RSS 和写入数据全部重测，见 [AOT 报告](AOT-PERFORMANCE.md)。包另经打包、内容和依赖检查、JIT 及 Native AOT 消费；公开源消费在发布后检查。
